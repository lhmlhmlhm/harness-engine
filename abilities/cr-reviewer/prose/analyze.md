# analyze 阶段：按优先级逐维度看，然后把发现分级并给出裁决

这是评审真正干活的一层，三步：五个维度逐一分析（`A01`）、把发现分级成文（`A02`）、给出裁决（`A03`）。

这一层的输出全是文字，没有任何不可逆动作——所以它也最容易被写得看着完整而实际空洞。判据在两个地方顶着它：`A01` 要求五个维度**每一个**都有结论（不许漏维度），`A02` 要求每条发现**都带分级**。这两条都不是形式：漏掉的维度在结果里看不出来，而没有分级的发现对作者是不可用的。

---

## Step: A01 按优先级逐维度分析

> - **输入**：`R02` 读到的 diff、改动文件清单与既有意见。
> - **输出**：五个维度各自的结论——正确性 / 安全 / 覆盖缺口 / 设计 / 风格。
> - **失败时**：某个维度在这次改动下不适用时记 `not_applicable`，不要留空。
> - **完成标准**：五个维度**每一个**都有结论（`clean` / `findings` / `not_applicable`），至少五条。

五个维度的顺序就是优先级，而这个顺序是有理由的：

1. **正确性**——它错了吗（bug、逻辑错、边界、空值、竞态）
2. **安全**——它能被滥用吗（注入、权限绕过、代码里的密钥、不安全的反序列化）
3. **覆盖缺口**——改了但没测（改动的代码路径有没有对应的测试更新）
4. **设计**——命名、抽象层次、重复、职责分离
5. **风格**——格式与约定

**判据要求五条，是因为漏掉的维度在结果里看不出来。** 一份只谈了设计和风格的评审读起来一样专业，而它可能完全没看正确性——而正确性是唯一一个「漏了会让错的代码合进去」的维度。写 `not_applicable` 是正当的（纯文档改动没有竞态可言），但它必须是一个明确的结论。

**风格这一维要特别克制：只在明显违背该库既有约定时才提。** 个人偏好不是发现。把「我会这样写」混进去的代价不是它本身占几行，而是它**稀释前四类的可信度**——作者读到第三条格式偏好时，会开始把整份评审当成风格挑刺，而你真正的正确性发现就在第四条。

## Step: A02 分级成文

> - **输入**：`A01` 的五维结论。
> - **输出**：每条发现带一个分级（阻断 / 建议 / 吹毛求疵）+ 一份成文的评审摘要。
> - **失败时**：零发现时明确说零发现，**不要为了显得认真而凑几条**。
> - **完成标准**：每条发现都有分级，摘要已记录。

三档分级：**阻断**（合入前必须修）、**建议**（推荐改进）、**吹毛求疵**（可选的小事）。

**分级是给作者用的决策信息，不是给你用的表达强度刻度。** 作者拿到评审后要决定「哪些必须现在改、哪些可以下一版、哪些无所谓」，而他做这个决定的依据就是你打的分级。所以打错的代价是不对称的：

- 把**建议标成阻断** → 作者被迫改一件本可以不改的事，或者要花时间说服你
- 把**阻断标成建议** → 作者合理地放过了它，而它是个真问题

这两个方向都是错的，但第二个错会进到主干里。判据要求每条都有分级，正是因为一条没分级的发现在作者那里等于「不知道该多认真对待」——而人在不确定时的默认反应是当成小事。

零发现的情形要明说。凑几条吹毛求疵来证明自己看过了，是把评审的信噪比主动拉低——而下一次你真有阻断级发现时，作者已经学会略读你的评审了。

## Step: A03 给出裁决

> - **输入**：`A02` 的分级发现与摘要。
> - **输出**：三者之一的裁决（通过 / 带意见通过 / 要求修改）+ 一句理由。
> - **失败时**：拿不定时选更保守的那个，并把犹豫的点写进理由。
> - **完成标准**：裁决取自封闭枚举（`approve` / `approve_with_comments` / `request_changes`）。

三个值是封闭的，因为裁决是要被别人当结论用的东西——「大致还行」不是一个能被消费的答案。

**有阻断级发现却给 `approve`，是把「我看过」当成了「这没问题」。** 这是这一步唯一真正的陷阱，而它很容易发生：你已经把问题写清楚了，感觉责任已经交付，于是裁决顺手给了通过。但裁决是那个会被读的字段——作者和后续的人看的是它，而不是你第三段里那条阻断。

`approve_with_comments` 存在正是为了这个中间态：有话要说但不拦住。而它与 `request_changes` 的界线就是分级：**有阻断 → 要求修改；只有建议和吹毛求疵 → 带意见通过。** 这条对应关系让裁决可以从分级推出来，也让「分级打错了」在这一步暴露出来——如果你发现自己想给通过而清单里有阻断，那大概是分级标高了，回 `A02` 改分级，而不是在这里放宽裁决。
