# 配置：把与改动无关的偏好先定下来

这个阶段只做一件事：在动代码之前，把**跟本次改动内容无关的偏好**一次性定好并持久化。
它解决的问题是「同一件事被后面好几步各问一次、还可能前后答得不一致」。做完的标准很清楚：
所有与 diff 无关的偏好都已写盘，且这一层唯一的确认 gate 已被如实记录。做不到这两点，
这一层就没完。

## Step: CF00 收集并持久化偏好（本层核心）

> - **输入**：任务/计划里预先声明的偏好字段 + 用户在 gate 处的回复
> - **输出**：一个持久化到运行状态里的 `config` 对象
> - **失败时**：某个必需偏好既没预授权、也没法从上下文推断 → 停下问人，不要替他默认一个
> - **完成标准**：① 偏好已写盘 ② 本步的确认 gate 已记录（`affirm`，或经显式预授权的 `preauth`）

**先分清哪些偏好属于这一层。** 只收「现在就能定、不依赖代码长什么样」的：用哪个分支、
找谁评审、要不要发布、发布后要不要自动合并、外部检查报问题时要不要自动修、要不要等
静态分析器跑完、测试用哪种策略。**明确不在这一层收**的是依赖 diff 的东西——提交信息要看
实际改了什么才能写，具体测哪些关键路径要先有 diff 才能算。这些留给后面看得到改动的阶段去解。
把两类混在一起，就会逼着这一步去猜它还看不到的东西。

**为什么要先把偏好定下来。** 这些值会被后面好几步反复读到：发布那一步读分支和评审人、
观察那一步读等待策略和自动修开关。不在这里定死，就会散落成后面每一步各问一次、或者各自
即兴填一个——同一个 run 里前后填的值还可能不一致。集中在这一步收齐、写盘一次，后面只读不问，
是为了让「这次要怎么发」有唯一、稳定、可回溯的答案。

**为什么不能让执行者即兴决定。** 这里的偏好里有一部分会触发**不可逆或影响他人**的动作
（自动合并、自动发布）。这类选择必须是「配置里明明白白写着的值」，不能是执行到某一步时临时
拍脑袋。执行者即兴填，等于把一个本该由人预先授权的决定，悄悄变成了自己的默认。

**default 是停下问人。** 没有显式预授权时，这一步就是一个 `affirm` gate：把解析出来的偏好
摊给人看，**结束这一轮**等真人回复；回复后才把值写盘并记录 gate。只有当配置里有一个**显式的
预授权开关**（一个明确写着「这些偏好已预先批准」的配置值）时，才退化成打印一行 notice、不拦人。

> ⚠️ **绝不要从「流程已经走到这一步」推断出预授权。** 「都进到配置阶段了、计划也确认过了，
> 应该算默认同意了吧」——这种推断是被明确禁止的。预授权**必须**是一个独立、显式的配置值；
> 只要你是靠「进度」而不是靠那个配置值去走预授权路径，gate 记录就会判定为伪造并**拒绝**
> （exit 非 0），同时记一条 violation。而这一层的完成标准之一正是「没有未决 violation」，
> 所以**推断一次，就把自己锁在这一层出不去**——这个咬合是故意设计的，不是可以绕过的边界情况。

**退化路径也必须写盘。** 就算走了预授权、不问人，也照样要把实际生效的偏好值写进运行状态。
「预授权」省掉的只是问人这一下，不是省掉持久化——后面的步骤仍要能读到这些值。还有一个容易
自欺的地方：预授权只在计划里**真的列全了那几个必需偏好**时才成立；缺了的偏好仍得停下来问，
不能因为「大部分都预授权了」就把剩下没写的也一并当成默认放过。

**有一个偏好决定「发布之后还追不追」。** 一个关键开关是：把改动推给代码评审系统之后，本流程
要不要继续自己盯着它。默认是「自己追」——发布后进入观察阶段，轮询外部检查、等静态分析器出
结论。也可以设成「发布即收手」——推上去就不再盯，后续追到上线交给外部接手。选了「收手」时，
后面那些「等分析器/自动修/自动合并」的偏好也就随之失效，因为没有 in-session 的追踪，它们
没有意义。这个选择现在就要定，因为它直接决定后面整段观察流程走不走。

**config 是 default，不是终判。** 这里定的是「打算怎么发」的默认值。等后面 diff 真出来、要
生成提交信息那一刻，仍允许人反悔覆盖（比如看到改动规模后临时改主意要不要自动合并）。覆盖会
回写 config 并标注来源。所以这一步不是「一锤定音」，而是「先给出一个可追溯、可被有依据地改掉
的起点」——它的价值在于让默认值有出处，而不是在于不可更改。

## Step: CF09 本层收尾打分

> - **输出**：本层的完成打分与交接标记
> - **完成标准**：CF00 已通过且 gate 已记录

发出本层的收尾打分，交接给下一阶段。恒执行——即便 CF00 走了预授权退化路径，这一步也照做。
